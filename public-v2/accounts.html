Pilih metode penambahan akun

Cara Kerja:

  1. Pilih mode (Cepat/Lengkap)
  2. Klik "Buka Browser & Login"
  3. Login di browser yang terbuka
  4. Tunggu sistem mengambil data
  5. Selesai!

Kenapa harus scrolling? Facebook tidak menampilkan semua grup sekaligus (lazy loading), jadi untuk dapat 400+ grup memang harus scrolling.

Cara Export Cookies:

  1. Install extension EditThisCookie atau Get cookies.txt
  2. Login ke Facebook di browser
  3. Klik extension → Export → Copy
  4. Paste di textarea di atas
